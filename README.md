✅ TaskFlow

Um gerenciador de tarefas desenvolvido com HTML, CSS e JavaScript puro, criado com o objetivo de praticar conceitos fundamentais do desenvolvimento Front-End, como manipulação do DOM, eventos, armazenamento local e organização de código.

📷 Demonstração

Adicione aqui uma captura de tela ou GIF da aplicação.

🚀 Funcionalidades
✅ Adicionar novas tarefas
✏️ Editar tarefas existentes
🗑️ Excluir tarefas
✔️ Marcar tarefas como concluídas
💾 Persistência dos dados utilizando LocalStorage
📱 Layout responsivo
⌨️ Adição de tarefas utilizando a tecla Enter
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript (ES6+)
LocalStorage
📚 Conceitos praticados

Durante o desenvolvimento deste projeto foram praticados diversos conceitos importantes do JavaScript, entre eles:

Manipulação do DOM
Eventos (click e keyup)
Criação dinâmica de elementos
Arrays e Objetos
Métodos como:
filter()
forEach()
at()
Organização do código em funções
Manipulação de classes com classList
Persistência de dados com LocalStorage
Conversão de objetos utilizando:
JSON.stringify()
JSON.parse()

Abra o arquivo index.html no navegador.

Nenhuma instalação adicional é necessária.

🎯 Objetivo do projeto

Este projeto foi desenvolvido como parte dos meus estudos em JavaScript com o objetivo de evoluir da manipulação básica do DOM para a construção de aplicações mais organizadas, utilizando boas práticas de programação e persistência de dados no navegador.
